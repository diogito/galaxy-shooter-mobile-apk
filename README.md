# Galaxy Shooter — Android APK

Builds del shooter arcade mobile (Unity 6000.3.25f1 + URP, IL2CPP, ARM64).

## v0.1.0
- Gameplay completo portado del prototipo web (waves, 3 tipos de enemigo, boss, powerups, combos)
- 5 naves 3D CC0 con PBR (glTFast)
- Audio procedural (9 voces sintetizadas)
- Touch controls: joystick virtual (izq) + zona de disparo (der)
- targetSdk 36, minSdk 25
